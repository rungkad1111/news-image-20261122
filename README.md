# news-image-20261122 — Sunday 22 November 2026 in one image

**"Sunday 22 November 2026 — 50 date-checked stories, 7 regions, a UTC timeline"**

One front page summing up the world's news of Sunday 22 November 2026:
50 stories (14 illustrated + 36 briefs) across 7 regions and 17 fields, a UTC
timeline with 6 timed anchors, a "Day in Numbers" strip, a world map with
numbered pins 1–14, a region bar, a "How sure" confidence legend, and a DATE
CHECK box naming the big Saturday stories deliberately left out.

The image covers the day so far — overnight and early morning UTC — with every
story verified as having happened or first been reported on 22 November 2026
in at least one timezone. See `stories.md` in the build notes for the
source + time of each story (kept with the builder's working files).

## How it runs

`main.ts` (Node 22, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). Both runs write the
same bytes.

## The image

- `entry.png` — 1024×1024, PNG, drawn flat in code (Python PIL). No
  photography, no copied artwork: every tile is a pictogram drawn from shapes.
